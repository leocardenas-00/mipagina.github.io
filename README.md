# Explicación
## Una página web estática sin base de datos con 4 pestañas en donde se seguía una estructura de HTML con un estilo de CSS y una lógica de JAVASCRIPT. Esta página fue hecha con un propósito personal, por ende, el código es básico, manejable y fácil de sobrescribir si hay necesidad de realizar cambios sin romper completamente la interfaz de la página.
## La página contiene:
- Imágenes
- Función de contador de tiempo
- Reproducción de canciones
- Función de imágenes aleatorias
- Función de escribir texto a velocidad controlada
  
Esas son las características que tiene la página web, no es un proyecto como tal, pero, pretendo que sea el comienzo de uno.
